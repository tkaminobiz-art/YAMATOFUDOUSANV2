## 9. 実装結果＆階層補正（2026-06-26・神野さん指示で実装）

### 補正の核心（最重要）
プラン §7 は「`600(132) > 3(124) > 2,280(108)` で全幅成立」としたが、これは **S03「600」を全幅 132px と誤算**していた。実測すると S03 `t-burn = clamp(64px,13vw,132px)` は **モバイルで下限 64px に張り付く**ため、当初実装値 `fv2-num3: clamp(112px,…)` だと 320–861px の全域で **`600(64–112) < 3(112)` ＝ 専務③ 降順（実績600 > 性能3 > 価格2,280）を破壊**していた（Playwright 実測で確認）。
