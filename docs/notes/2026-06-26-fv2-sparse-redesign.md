# FV② xmobile式スパース再設計（2026-06-26）

## 経緯
神野さん（AD）の問い「そもそも xmobile の文字数と同じになってるか？」を起点に検証した結果:

- **xmobile の FV 巨大文字は画像焼き込み**（`slide0101.webp` 2005×297 の文字帯＋`s0102.png`）。DOM ライブテキストは 14px ナビのみ＝「文字数・フォントサイズ」を DOM から 1:1 移植することは不可能。合わせられるのはスクショから起こした見た目だけ。
- xmobile FV は極端に**スパース**: 巨大緑数字「1,026」社（約127px・1発のみ）＋ 極少バッジ（平均年商900万円 等）＋ 大ゴシック一文「いま、本業＋求められています。」。**①巨大数字は1発 ②大量の黒余白 ③説明文を足さない**。
- 旧 FV②は見出し14字・価格5字・巨大数字124px と「字数・サイズ」は xmobile 並みだったが、**その下に標準仕様帯（ブランド7枠）＋多数の本文**を足し、セクション全体の密度が xmobile と別物（詰め込み＝table-smell）だった。

**神野さん決定（2026-06-26）= 「xmobile式に振り切る（スパース化）」。**

## 設計（デザインチーム workflow `wsuuyvow7`：3案→9審査→統合）
