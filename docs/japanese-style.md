# 日本語スタイルガイド（サイト全体）

## 目的
「正しい敬語」よりも、読み手が**安心して読み続けられる自然さ**を優先する。  
やまと不動産のトーンは **静かな信頼 / 正直 / 余韻**。

## 基本文体
- **です・ます**基調（過剰敬語は避ける）
- 「でございます」「〜いたします」は連発しない  
  - 例：×「ご説明いたします」→ ○「ご説明します」/ ○「ご案内します」
- 「あなた」は多用しない（押し付けが出る）  
  - 例：○「ご家族に合わせて」○「状況に合わせて」

## “美しい日本語”の入れ方（やりすぎない）
- 情景語・余韻は**見出し／締めの一文**にだけ使う（本文に連打しない）
- “侘び寂び”は語彙ではなく**間（余白）と断定しない言い方**で出す  
  - 例：○「〜の場合があります」○「条件次第で」

## NGになりやすい語
- 不自然語：**お申請** / **お代** / **手当て（医療寄り）** / **畳みかける（攻撃的）**
- 断定リスク：**絶対** / **必ず** / **ございません**（金融・保証等）

## 言い換えの定番
- でございます → です
- ご来場のおりに → 来場時に
- お手続き費用 → 手続き費用 / 〜に関わる費用
- いたします → します（必要なら「いたします」は要所に残す）
- お仕立て直し → つくり直し / 仕立て直し（硬さを見て選ぶ）

## 数字・注記の作法
- 数字は「目安」「条件により」で**逃げ道を明記**
- 注記は短く、同じ語尾を続けない（です／ますで閉じる）
