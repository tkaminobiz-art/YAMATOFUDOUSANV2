# 2026-04-28 小林専務レビュー結果と 8 つの原則

2026-04-28 に小林専務 (代表取締役専務 / 小林 敬昌) に新サイト現状レビュー実施。
「今までで一番しっくりきてる」「早くアップしなくていいから練り込んで」と
**品質優先で承認**された。

## 背景

旧サイトは 21 秒離脱。専務は旧サイト=物件押し出し型を**失敗と自認**。
「アクションの仕方が全然違うな」「物件をガンガン押し出してただけなのかもしれへんな」
と発言。広告費は SUUMO と弊社のみで、HP は事実上の主戦場。
専務は神野 (AD) に**全権委任に近い信頼**を置いている = 「言われた通り」では不十分、
超える提案を期待されている。

## 専務の本音 8 点 (全実装判断の基準)

### 1. 物件押し出し型からの脱却

FV に物件を出してはいけない。物件・土地動線は興味を深めた後の出口に配置。
LINE 土地配信も FV 外。

### 2. 真のターゲットは他府県 (大阪・京都からの移住者)

地元客ではない。「大安寺と言われてもピンとこない」発言が根拠。
地図 UI・暮らし方タグ・他府県アクセス情報の優先度を一段上げる。

### 3. 「めちゃめちゃ量産やってはんねんな」の権威性は "バーン" 配置

600 棟・区画数はダッシュボード統合ではなく、**FV 直下に単独で大きく主役級**
に置く。小さくまとめると専務の意図と逆になる。

→ 現状 `HeroVideo` の TRACK RECORD overlay (4 指標) で実装済み。

### 4. 「家は投資」哲学は本気だが "エッセンス" 指定

専務本人が「エッセンスを加えてくれたらなお良し」と語尾控えめに指定済み。
- メイン: 「資産として残る」
- サブコラム: 「住宅ローンを賢く使う金融視点」
- NISA 直接比喩は避けつつ、低金利・長期借入の視点はエッセンスとして温存
- **完全削除は専務哲学を半殺しにするので NG**

### 5. 動画資産は既にある + これから撮る + 現場でも気をつける

コンテンツ供給側 (専務側) が動く前提。投資する価値あり。
ただし**運用の役割分担を最初に決めないと止まる**。

### 6. 「お客さんごとのルームツアー動画」は施工事例ページの話

仕様動画とは別の明示要望。過去施工事例ページに動画埋め込み。

### 7. 「99.9% そのまま」哲学 → 声を編集しない

カテゴリ分け再配置は良い案だが、**声本体は編集せずタグ付け → 各ページ引用形式**
に留める。

### 8. 「練り込んで」= 数より質

P1 で 7 項目並列は NG。**P1 は 3〜5 項目に絞り深く作る**。
