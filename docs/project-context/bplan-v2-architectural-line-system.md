## 1. 視覚言語の核

### 画風「Architectural Line（温かいヘアライン）」
既存 `StandardComparisonBlueprint.tsx` の `HouseDrawing`（建築elevation線画）を**全図解の主役に昇格**。ゼロから別画風を持ち込まない＝AIっぽさ回避の最大担保。

- **線3階層**（`vector-effect:non-scaling-stroke`）：主線1.25-1.5px／寸法線0.6-0.75px／赤強調1.75px。`stroke-linejoin/linecap:round`、端点に±0.3px手ゆらぎ＝定規＋手の温度。
- **彩色**：モノライン（線＝深緑#195842 or ink#181714）。塗りは半透明差し色のみ（深緑6-14% opacity）＋生成り#f4efe6地。テラコッタ#8a5232は線1本/小ドットの微差し（全図5%未満）。**グラデ・多色塗り・影は禁止**。
- **赤#ea4b2a**：要確認/リスク/総額診断のみ（BRAND-TRUTH §1）。
- **却下画風と理由**：カラフルflatイラスト（AI感最強・実写と衝突・§1違反）／アイソメ主役（SaaS臭）／コラージュ（装飾過多再発）／太い手描き（プレミアム消失）。
- 補助：生成り紙テクスチャ＋極小ピクト（下地のみ・全面ドット禁止・連続2セクション禁止）。
- 統一アイコン：ストローク1.25px・24/32/48pxグリッド・角round・塗りなし・1モチーフ1意味。

### タイポ/カラー/余白（既存トークン据え置き＝漂流しない）
- 声量3段階：shout(数字 Oswald 300, clamp56-104px・ページ1-2回)／talk(見出し Zen Old/Shippori Mincho 500, clamp28-40px)／whisper(eyebrow/lead Murecho)。図中テキストも同トークン。
- カラー（実コード`P`が正本）：ink#181714 / white#fffdfa / paper#f4efe6 / smoke#ece6db / green#195842 / red#ea4b2a / rust#8a5232（a11y AA対応の濃いテラコッタ）/ line rgba(24,23,20,.16) / mute#716b61。内訳は深緑3明度段。青・水色・蛍光禁止。
- 背景は明度を波打たせる（暗→white→暗→paper→white(クライマックス)→smoke…）。図解の地は基本 paper か white。
- モーション：`ReasonReveal`/`AnimatedNumber`流用（reduced-motion対応）。カウントアップは月々だけ。線画は stroke-dashoffset の「描かれる」アニメを1セクション1回まで。≤0.6s・バウンス/回転/色フラッシュ禁止。

## 3. 写真の扱い（違和感の核＝解決済み方針）

- **家・内観・人物は実写真のみ**（AI完成予想図は禁止＝BRAND-TRUTH §1）。図解が担うのは「写真が語れない不可視の論理（お金/年数/工程/仕組み）」だけ。面積比は写真＞図解。
- **写真治療（実写ルール内＝AGENTS.md「既存シーンの整理・フレーミングはOK」）**：①最上位カットのみ採用（living-05/06/11・外観夜景が格上。living-01は弱い）②編集的クロップで雑物(パンフラック/TV)を外す③暖色エディトリアルグレードでトーン統一（ImageMagick: `-modulate 104,87 / R×1.05 B×0.96 / sigmoidal-contrast 2,52%`）④図解が概念を担うので写真は少数精鋭。
- **適用済**：Hero写真を living-01 → グレード済 living-05（`public/images/bplan/hero-interior-v2.webp`）。
- ヒーロー級の撮り直し（ゴールデンアワー・編集的フレーミング・スタイリング）は最終解として制作側へ提言。
