# やまと言葉バンク（一次資料・逐語）

> **目的**：やまと不動産が「実際に使っている言葉」を一次資料からそのまま蓄積する逐語コーパス。
> コピーライティング（copywriter スキル）が `素の説明体` の北極星＝クライアントの実テキストとして参照する。
> **改変・要約せずに引用する。** ここから言い回しを借りるときは register（口調・温度）を合わせる。
>
> **出典は2系統**
> - `[公式]` … 公式サイト https://www.yamatogroup.net/ の逐語（WebFetch・2026-06-23取得）。各行末にページパス。
> - `[パンフ]` … 神野さん撮影のパンフレット写真13枚の逐語。小さい数字・約款級は `〔要原本確認〕`。
>
> **数字の正本は BRAND-TRUTH.md。** ここに採録した数字（区画数・保証年数等）に公式サイトとの差異がある場合は §9 に明記。コピーに使う数字は必ず BRAND-TRUTH を最終確認する。
>
> 最終更新：2026-06-23

---

## §0. このバンクの使い方（copywriter 向け）

1. 新規コピー／リライトの前に、該当テーマの節を**音読**する。やまとの温度（少しラフ・対面の説明・誇示しない）を口に入れてから書く。
2. 抽象名詞（暮らし／想い／安心）で締める衝動が出たら、ここの**具体の言い回し**に差し替える。
3. `[公式]` の言い回しは「実在のスタッフが客の前で言う言葉」として既に検証済み。迷ったらこちらに寄せる。
4. ここに**無い**数字・固有名詞は創作しない（BRAND-TRUTH §2 を見る）。
